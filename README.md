## About the Project

The **Online Examination System** allows users to take a 100-question timed test (90 minutes). It includes question navigation, review marking, image support, and automatic scoring.

---

## Features

✅ Start screen with instructions  
✅ Timer (90 mins, auto-submit)  
✅ Question navigation (sidebar + arrow keys)  
✅ Mark for Review option  
✅ Results modal (correct, incorrect, unanswered, final score)  
✅ Image support (questions q40–q60)  
✅ Responsive design  
✅ Keyboard shortcuts (`←`, `→`, `M`)

## Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Edge)
- VS Code (optional, for development)
- Git (for version control)

### Installation

1. Clone the repo
   ```bash
   git clone https://github.com/Mahesh-more1/online-examination-system.git
   ```
2. Navigate into the project
   ```bash
   cd online-examination-system
   ```
3. Run
   - Open `index.html` in your browser  
   - OR use **Live Server** in VS Code

---

## Usage

- Start the exam → Read instructions → Click "Start Exam"  
- Navigate using buttons or arrow keys  
- Press `M` to mark for review  
- Submit manually or wait for auto-submit  

Example question:  
*"What is 2 + 2?" Options: [1] [2] [3] [4]*

## Deployment

This project can be deployed easily via **GitHub Pages**:

1. Push the repo to GitHub  
2. Go to **Settings → Pages**  
3. Select **Branch: main → /(root)**  
4. Get your live link:  
   ```
   https://mahesh-more1.github.io/online-examination-system/
   ```

Alternative: Deploy on **Netlify** or **Vercel** with drag-and-drop.
